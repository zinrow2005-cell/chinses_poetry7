PKG374｜書法練習體驗優化版

本版重點
1. 新增畫布外「練習進度列」：上一個／目前字與進度／下一個固定位置，不遮住書寫畫布。
2. 單字、句子、全文模式可在進度列直接切換，手機不必打開設定面板。
3. 底字濃度加入「淡／標準／深」三段一鍵切換，並保留原細部滑桿。
4. 格線改為單鍵循環：米字格 → 方格 → 橫線 → 空白；設定會記住。
5. 下一個沿用既有安全行為：切換時自動清除上一個字的筆跡，不增加多餘確認步驟。
6. 全文模式會自動隱藏上一個／下一個，避免無效按鈕干擾。
7. 手機與 iPad 版將原工具列重複的上一個／下一個隱藏，減少重複控制與誤觸。
8. 底字濃度與紙張樣式使用 localStorage 保存，下次開啟沿用。
9. 所有新增控制放在畫布外，不以浮層覆蓋書寫區。

檢查項目
- HTML 結構與 ID 重複檢查
- inline JavaScript 語法檢查
- manifest JSON 檢查
- 本機檔案引用檢查
- ZIP 完整性檢查
