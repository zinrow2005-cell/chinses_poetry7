胖超詩詞閱讀書寫系統 PKG372｜操作流程精簡與防遮擋修正版
日期：2026-10-04

本版完成：
1. 手機底部導覽由 6 個按鈕精簡成 5 個：閱讀／篩選／作品／學習／書寫。
2. 修正前一版「6 個按鈕卻使用 5 欄 grid」造成窄螢幕擠壓或遮擋的結構問題。
3. 手機作品庫點選作品後，直接回閱讀畫面，不再需要再按一次關閉。
4. 閱讀頁加入單鍵「書寫」快捷入口。
5. 手機閱讀頁隱藏重複的朗讀控制，只保留常用操作，減少同功能按鈕重複。
6. 閱讀分頁列改為可橫向滑動，窄螢幕不硬擠、不互蓋。
7. 書寫頁手機／iPad 預設隱藏次要筆刷設定，需使用時再按「筆刷設定」展開。
8. 390px 以下手機將句子／全文模式收進「模式」，減少第一排工具擁擠。
9. 書寫常用按鈕文字縮短：上一個／下一個／復原／清除，降低工具列寬度。
10. 「清除」改成 1.6 秒內再按一次才執行，避免快速操作誤清整頁。
11. 手機／iPad 的畫布、工具列、底部浮動操作列重新分配可視高度與 safe-area。
12. 旋轉裝置或尺寸變化時，自動收合暫時展開的設定區，再重新校正畫布。
13. 保留 PKG370 的全站防誤全選設定；輸入框仍可正常選字輸入。
14. HTML 本機 href/src 引用檢查：無缺檔。
15. index / reader / writing / mobile：無重複 id。
16. 所有 inline JavaScript 已以 Node --check 驗證：0 個語法錯誤。

測試說明：
- 已啟動 Chromium 進行自動化嘗試，但目前容器環境對 localhost/file 頁面導覽產生 chrome-error://chromewebdata/，因此無法把完整點擊自動化結果當成真實裝置驗證。
- 本版修正依據為實際 DOM/CSS/JS 結構檢查、事件流程檢查、語法檢查與跨尺寸規則檢查。
- 上 GitHub Pages 後仍建議在 iPhone/Android、iPad 直橫向與桌機各操作一次；若有畫面截圖即可直接針對真實 Safari/Chrome 差異修正。
