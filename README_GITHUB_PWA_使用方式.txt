胖超詩詞閱讀書寫系統 PKG369｜GitHub Pages 上傳方式

1. 解壓縮本 ZIP。
2. 將全部檔案覆蓋到 GitHub repo 根目錄。
3. 確認 repo 根目錄包含：
   - index.html
   - mobile.html
   - reader.html
   - writing.html
   - manifest.webmanifest
   - service-worker.js
   - icons/
   - splash-screen.png
   - .nojekyll
4. 等 GitHub Pages 更新完成後，用無痕視窗或手機瀏覽器開啟測試。
5. 手機若仍讀到舊版，請刪除主畫面 APP 並清除網站資料。
